Lenguajes y un ejemplo de código real.

Para desarrollar sistemas de IA se utilizan lenguajes de programación y herramientas que permiten trabajar con datos, algoritmos y modelos. Python es uno de los lenguajes más utilizados en este campo gracias a su sintaxis sencilla y a sus bibliotecas especializadas.

# Ejemplo muy simple de una regla de decisión def es_correo_spam(texto): palabras_sospechosas = ["gratis", "gana dinero", "urgente"] return any(palabra in texto.lower() for palabra in palabras_sospechosas)
