¿Qué es la IA?

La definición básica y cómo aprenden las máquinas.

La Inteligencia Artificial es un conjunto de técnicas que permite que las máquinas procesen información y realicen tareas de forma similar a algunas capacidades humanas, como observar, escuchar, leer y decidir.

Para lograrlo, los sistemas de IA se entrenan con grandes cantidades de datos y algoritmos que encuentran patrones; entre más ejemplos analizan, mejores resultados suelen obtener.

No se trata de que la máquina "piense" como una persona, sino de que reconoce patrones matemáticos en la información que recibe y los usa para dar una respuesta útil. El siguiente diagrama resume ese proceso:

Los datos entran al algoritmo o modelo, y este produce un resultado: una predicción, una clasificación o un texto nuevo.

¿Cómo aprende una IA?

El aprendizaje de una IA se parece a estudiar para un examen: se practica con ejemplos y después se comprueba qué tanto se aprendió.

  1. Reunir datos

    Se juntan muchos ejemplos: fotos, textos, audios o números relacionados con el problema que se quiere resolver.

  2. Entrenar el modelo

    El algoritmo analiza los ejemplos, busca patrones y ajusta sus parámetros internos para equivocarse cada vez menos.

  3. Evaluar

    Se prueba con datos nuevos, que el modelo nunca vio, para comprobar si realmente aprendió y no solo memorizó.

  4. Usar y mejorar

    Se pone a trabajar en la vida real y se sigue corrigiendo con nueva información cuando es necesario.

Programa tradicional frente a inteligencia artificial

La gran diferencia está en quién escribe las reglas.

CaracterísticaPrograma tradicionalSistema de IA
ReglasLas escribe la persona que programa, una por una.El sistema las deduce a partir de ejemplos.
DatosSe usan para obtener un resultado.Se usan para aprender; sin datos no hay aprendizaje.
MejoraSolo cambia si alguien modifica el código.Puede mejorar con más ejemplos y entrenamiento.
EjemploUna calculadora.Un reconocedor de voz.

Conceptos que conviene conocer

Estas ideas aparecen una y otra vez cuando se habla de IA. Las encuentras explicadas en el glosario.

  • Aprendizaje automático
  • Aprendizaje profundo
  • Red neuronal
  • Modelo de lenguaje
  • IA generativa
  • Visión artificial

En resumen: el aprendizaje profundo es una parte del aprendizaje automático, y el aprendizaje automático es una forma de lograr inteligencia artificial.

¿Sabías que?

Una IA puede ser muy buena en una sola tarea, como jugar ajedrez, y no saber hacer nada más. Por eso se dice que hoy casi toda la IA es especializada.
