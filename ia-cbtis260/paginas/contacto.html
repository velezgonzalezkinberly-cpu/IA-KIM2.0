Datos del proyecto.

Proyecto escolar de aplicación Web sobre Inteligencia Artificial.

CBTIS 260

Este sitio fue creado por Kinberly Vélez González como una aplicación web progresiva (PWA): se puede instalar en el celular o la computadora y consultar incluso sin conexión a internet.

Tecnologías utilizadas

  • HTML
  • CSS
  • JavaScript
  • PWA (manifest y service worker)
  • PHP
  • MySQL
  • Voz del navegador

Cómo instalar la aplicación

  1. En Android

    Abre el sitio en Chrome, toca el menú de tres puntos y elige «Instalar aplicación» o «Agregar a la pantalla de inicio».

  2. En iPhone

    Abre el sitio en Safari, toca el botón Compartir y elige «Agregar a pantalla de inicio».

  3. En computadora

    En Chrome o Edge, pulsa el icono de instalar que aparece en la barra de direcciones.

Cómo escuchar las páginas

En todas las secciones hay un botón flotante con una bocina, en la esquina inferior derecha. Al tocarlo se abre el lector: puedes reproducir, pausar, detener, saltar al texto anterior o siguiente y cambiar la velocidad. Con el lector abierto, también puedes tocar cualquier párrafo para que la lectura empiece desde ahí.
