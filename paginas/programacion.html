Programación

Lenguajes y un ejemplo de código real.

Para desarrollar sistemas de IA se utilizan lenguajes de programación y herramientas que permiten trabajar con datos, algoritmos y modelos. Python es uno de los lenguajes más utilizados en este campo gracias a su sintaxis sencilla y a sus bibliotecas especializadas.

Este primer ejemplo es una regla de decisión muy simple: una función que revisa si un texto contiene palabras sospechosas y responde si podría ser spam.

# Ejemplo muy simple de una regla de decisión def es_correo_spam(texto): palabras_sospechosas = ["gratis", "gana dinero", "urgente"] return any(palabra in texto.lower() for palabra in palabras_sospechosas)

Un ejemplo con aprendizaje automático

En este ejemplo, en lugar de escribir las reglas, le damos al programa algunos casos con la respuesta correcta y él aprende a distinguir una manzana de una naranja según su peso y su textura. Es un ejemplo de juguete, pero muestra la idea del aprendizaje supervisado.

from sklearn.tree import DecisionTreeClassifier # [peso en gramos, textura: 0 = lisa, 1 = rugosa] datos = [[150, 0], [170, 0], [140, 1], [130, 1]] frutas = ["manzana", "manzana", "naranja", "naranja"] modelo = DecisionTreeClassifier() modelo.fit(datos, frutas) # aprende de los ejemplos print(modelo.predict([[160, 0]])) # ['manzana']

Pasos de un proyecto de IA

  1. Definir el problema

    Decidir qué se quiere resolver y cómo se medirá el éxito.

  2. Conseguir y limpiar datos

    Reunir ejemplos y corregir errores o datos incompletos.

  3. Entrenar el modelo

    Elegir un algoritmo y dejar que aprenda de los datos.

  4. Evaluar

    Probar con datos nuevos y medir qué tan bien funciona.

  5. Publicar y vigilar

    Ponerlo en uso y revisar que siga funcionando bien con el tiempo.
